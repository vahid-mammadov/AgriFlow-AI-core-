# AgriFlow AI Core

The core backend and AI engine for the AgriFlow AI FinTech project. This repository handles the FastAPI server and the XGBoost prediction model.

## Project Structure

- `main.py` - Main FastAPI application and API routes
- `model/` - Contains the trained XGBoost model (`agriflow_xgboost.json`) and training script
- `data/` - Dataset files used for the project
- `requirements.txt` - Project dependencies

## Getting Started

1. Clone or download this repository.
2. Open your terminal in the project folder and install the required dependencies:
   ```bash
   pip install -r requirements.txt
